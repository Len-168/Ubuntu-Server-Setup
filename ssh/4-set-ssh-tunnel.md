## 1. Install cloudflared on Ubuntu
For your setup, ` I recommend running cloudflared directly on Ubuntu as a systemd service`, rather `than inside Docker`.
That way remote administration of the machine does not depend on your Docker stack being healthy.

1.1. Install Cloudflare's repository

```bash
sudo mkdir -p --mode=0755 /usr/share/keyrings
```

```bash
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg \
  | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
```

1.2. Add the repository

```bash
echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main" \
  | sudo tee /etc/apt/sources.list.d/cloudflared.list
```

1.3. Install cloudflared

```bash
sudo apt install -y cloudflared
```

1.4. Verify
```bash
cloudflared --version
```

## 2. Configure Cloudflare Access first
This step is important.
Do this `before publishing the SSH hostname.`

2.1. Go to Cloudflare:

```text
Zero Trust
   ↓
Access controls
   ↓
Applications
   ↓
Create new application
   ↓
Self-hosted and private
   ↓
Add public hostname
```

2.2. Destinations

Entry hostname
```text
Add subdomain + domain

# Example
ssh.YOUR-DOMAIN.com
```

2.3. Create a policy like:

```text
Policy name: Home Lab Admin

Action: Allow

Include: Emails

Value:
your-email@example.com

# Then Save policy
```

## Optional: Enable email OTP

Cloudflare changed this recently: new Zero Trust organizations now use the `Cloudflare identity provider by default`,
and OTP is no longer automatically configured.
If you specifically want the "send code to my email" flow, enable OTP manually.

Go to:

```text
Zero Trust
   ↓
Integrations
   ↓
Identity providers
   ↓
Add new identity provider
   ↓
One-time PIN
```

Enable:

```text
One-time PIN
```

Then return to your SSH Access application and allow your email.

The login process becomes:

```text
ssh command
     ↓
Cloudflare login page
     ↓
Enter email
     ↓
OTP sent to email
     ↓
Enter OTP
     ↓
Cloudflare Access passes
     ↓
SSH server
     ↓
SSH private-key authentication
     ↓
Ubuntu shell
```

Cloudflare says these OTPs are single-use and expire 10 minutes after they're requested. Cloudflare Docs
For a personal home lab, Cloudflare Account authentication with MFA is stronger and more convenient long-term than email OTP, but OTP is perfectly reasonable for learning/testing.


## 3. Create the Cloudflare Tunnel

3.1 Go to:

```text
Cloudflare Dashboard
   ↓
Networking
   ↓
Tunnels
   ↓
Create Tunnel
   ↓
Choose Cloudflare
   ↓
Select Cloudflare
```

3.2 Give name (What you want)

```text
#Name your tunnel
ubuntu-home-lab
```

Cloudflare will give you an installation command containing a token, similar to:

```bash
sudo cloudflared service install eyJhIjoi...
```
Run the command generated by your dashboard on Ubuntu.
Do not paste that tunnel token anywhere public.

3.3. Check:
```bash
sudo systemctl status cloudflared
```
```text
Active: active (running)
```
Cloudflare's current dashboard-managed tunnel setup installs the connector as a system service using that tunnel token. Cloudflare Docs
